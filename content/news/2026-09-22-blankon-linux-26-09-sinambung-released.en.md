# BlankOn Linux 26.09 Sinambung Officially Released

---

![BlankOn Linux 26.09 Sinambung release poster](/content/assets/blankon-sinambung-release-poster.jpeg)

After 303 days since the previous release on November 23, 2025, BlankOn Linux 26.09 Sinambung, with the ISO codename Verbeek, has been officially released.

Sinambung is a rolling release based on Debian Sid. Packages from Debian Sid are first synchronized to a staging repository, where they go through testing before being promoted to the user repository. With this approach, BlankOn Linux aims to deliver the latest packages from Debian Sid with a more stable user experience.

## Download BlankOn Linux Sinambung

BlankOn Linux Sinambung can be downloaded from [blankonlinux.id](/en/download).
